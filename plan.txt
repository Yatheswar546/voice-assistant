Complete Roadmap for Sidebar Module:

Module 11.1 - Sidebar Backend APIs

This is the foundation. We'll build APIs like:

GET    /api/sessions
Returns all sessions of the logged-in user.

[
  {
    "_id": "...",
    "title": "...",
    "updatedAt": "..."
  }
]

GET    /api/sessions/:id/messages
Loads messages for a selected session.

[
    {
        "role":"user",
        "message":"..."
    },
    {
        "role":"assistant",
        "message":"..."
    }
]

PATCH /api/sessions/:id
Rename chat.

DELETE /api/sessions/:id
Delete chat.

Without these APIs the frontend cannot become dynamic.

Module 11.5 - Session Grouping

This is a surprisingly interesting feature. MongoDB will return something like

Session A
Created yesterday

Session B
Created today

Session C
Created last week

Session D
Created 2 months ago

We need to group them into

Today

Yesterday

Previous 7 Days

Previous 30 Days

Older

This grouping should not happen inside the UI. It belongs in a utility/helper.
Something like

"utils/groupSessions.ts"
or
"services/sessionGrouping.ts"

That keeps React components very clean.

Module 11.7 - New Session

This is more than just clearing the screen. It should

Clear Messages
↓
Reset Active Session
↓
Wait for First Prompt
↓
Create Session after first message

Notice something. We should not create an empty session immediately.

We already designed the backend to create a session only after the first message arrives. That avoids storing lots of empty conversations.
